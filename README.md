**Customer Purchase Behavior Analysis using Python, PostgreSQL & Power BI**

Overview:
This project focuses on analyzing customer purchase behavior using data analytics techniques. The workflow includes data loading, cleaning, exploratory data analysis (EDA), SQL-based business analysis, dashboard creation, and reporting to generate actionable insights from customer purchasing patterns.

The project demonstrates an end-to-end analytics pipeline using Python, PostgreSQL, and Power BI.

Dataset:
The dataset contains customer purchase information including:
Customer demographics (Age, Gender)
Product and category information
Purchase amount details
Review ratings
Shipping preferences
Subscription status
Previous purchase history
Discount information

Tools & Technologies Used:
Python
Pandas
NumPy
Matplotlib
Seaborn
Database
PostgreSQL

Visualization:
Power BI
Environment
Jupyter Notebook
pgAdmin

Project Workflow
1. Data Loading
Imported dataset using Python
Performed initial inspection
Checked structure and data types
2. Exploratory Data Analysis (EDA)
Performed analysis including:
Distribution analysis
Missing value detection
Purchase pattern analysis
Category analysis
Customer behavior analysis
3. Data Cleaning
Removed missing values
Fixed incorrect data types
Removed duplicates
Created additional features where required
4. SQL Analysis using PostgreSQL
Business questions answered using SQL:
Customer Spending Analysis
Customers using discounts while spending above average
Comparison of spending patterns
Product Analysis
Top-rated products
Most discounted products
Most purchased products within categories
Customer Segmentation
New customers
Returning customers
Loyal customers
Subscription Analysis
Revenue comparison between subscribers and non-subscribers
Repeat buyer subscription behavior
Revenue Analysis
Revenue contribution analysis

The Power BI dashboard includes:
Sales Overview

Revenue Analysis
Discount Impact Analysis

Dashboard Features:
Interactive filters
KPI cards
Trend analysis

Revenue visualizations
Results & Insights

Some key findings:
Identified high-spending customers even when discounts were applied
Found top-performing products based on customer reviews
Analyzed purchasing behavior between subscribers and non-subscribers
Segmented customers based on purchase history
Evaluated revenue contribution patterns

Conclusion
This project demonstrates an end-to-end data analytics workflow involving data preprocessing, SQL analysis, visualization, and reporting to derive meaningful business insights from customer purchase behavior.
